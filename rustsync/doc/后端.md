# nvr-server

打包
```sh
docker run -it --name=pyRust -v D:\github:/app python:3.11-alpine3.20 /bin/sh
```

```sh
apk add binutils
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
pip install pyinstaller
cd /app/rust-sync/backend
pip install --no-cache-dir -r requirements.txt
pyinstaller -n RustSync -F main.py
```

打镜像

```sh
docker build -t dr34m/rust-sync:0.1.5 .
docker tag dr34m/rust-sync:0.1.5 dr34m/rust-sync:latest
```

运行命令

```sh
docker run -d -p 8023:8023 -v D:\opt\app\RustSync:/app/data --name=RustSync dr34m/rust-sync:latest
```
